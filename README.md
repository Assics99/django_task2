# Пульт охраны банка

Внутренний веб-сервис для службы безопасности банка. Сайт подключается к базе данных пропусков и позволяет следить за доступом в хранилище в реальном времени.

### Возможности
* Просмотр списка всех активных пропусков.
* Мониторинг сотрудников, которые прямо сейчас находятся в хранилище, с таймером их пребывания.
* Просмотр истории визитов по конкретному пропуску с автоматической пометкой подозрительно долгих визитов (более 60 минут).

### Как установить

Для работы сайта нужен установленный **Python 3.8+** и доступ к базе данных **PostgreSQL**.

1. Скачайте код репозитория:
```bash
git clone https://github.com
cd django_task2
```

2. Установите зависимости с помощью `pip` (рекомендуется использовать виртуальное окружение):
```bash
pip install -r requirements.txt
```

### Переменные окружения

Часть настроек проекта берётся из переменных окружения. Чтобы их определить, создайте файл `.env` в корневой папке проекта и запишите туда данные в формате `ПЕРЕМЕННАЯ=значение`.

Доступны следующие переменные:
* `SECRET_KEY` — секретный ключ Django для криптографической подписи и защиты данных (должен быть уникальным и храниться в тайне).
* `DB_HOST` — адрес сервера, на котором запущена база данных PostgreSQL (например, `localhost` или IP-адрес).
* `DB_PORT` — порт для подключения к базе данных PostgreSQL (обычно `5432`).
* `DB_NAME` — название базы данных, из которой будут загружаться пропуски и визиты.
* `DB_USER` — имя пользователя для авторизации в базе данных.
* `DB_PASSWORD` — пароль пользователя базы данных.
* `DEBUG` — режим отладки Django. Принимает `True` или `False` (по умолчанию `False`). При значении `True` на страницах ошибок выводится подробная техническая информация для разработчиков; в рабочем режиме (`False`) она скрыта.
* `ALLOWED_HOSTS` — список разрешённых доменов и IP-адресов через запятую, с которых можно обращаться к сайту (по умолчанию `127.0.0.1,localhost`).

Пример содержимого файла `.env`:
```env
SECRET_KEY=ваш_секретный_ключ
DB_HOST=localhost
DB_PORT=5432
DB_NAME=bank_security
DB_USER=postgres
DB_PASSWORD=secret_password
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
```

### Как запустить

Запустите локальный сервер командой:
```bash
python manage.py runserver 0.0.0.0:8000
```

Пример вывода в консоль после успешного запуска:
```text

Performing system checks...
```

После запуска сайт будет доступен в браузере по адресу: `http://127.0.0`
